# sektraproject
This project predicts customer churn for a telecom company using Azure Machine Learning and Azure AutoML to enable targeted retention programs. Initially, data on customer demographics, account information, and service usage is collected and preprocessed, involving data cleaning and feature engineering. Missing values are handled, outliers are addressed, and inconsistencies in the data are corrected. Azure AutoML is used to automate the selection and training of the best machine learning model, with the best-performing model being a voting classifier that achieves an accuracy of 80%. This ensures robust predictions for identifying at-risk customers.

The trained model is then registered and deployed in Azure Machine Learning, with an optimal inference configuration that includes a scoring script and environment dependencies. Thorough endpoint testing is conducted to verify the model's accuracy and performance. To secure data, service endpoint policies are implemented to restrict data transfer to only authorized Azure Storage accounts, preventing unauthorized data exfiltration. Additionally, an Azure Resource Manager (ARM) template is used to automate infrastructure setup, ensuring consistent and repeatable deployments.
